# 蓝禾技能库

蓝禾专属 AI 技能库，为 OpenClaw 智能助手提供专业领域能力。

---

## 🚀 快速开始

### 调用技能

发送 `蓝禾技能：你的问题`，AI 会自动匹配并执行相关技能。

**示例**：
- `蓝禾技能：标题怎么写` → 匹配「亚马逊标题优化」技能
- `蓝禾技能：设备异响` → 匹配「工厂设备故障排查」技能
- `蓝禾技能：客户投诉` → 匹配「客服话术」技能

### 上传新技能

1. 在对话中描述技能需求，AI 生成 SKILL.md
2. 确认 SKILL.md 内容
3. 发送 `上传蓝禾技能`
4. AI 生成摘要 → 确认 → 自动推送到 GitHub

## 🔧 核心设计

### manifest.json - 统一索引

每次上传新技能时自动更新，调用时只读这一个文件。

```json
{
  "version": "2026-03-25",
  "updated_at": "2026-03-25T16:16:00Z",
  "skills": [
    {
      "skill_id": "amazon-title-optimization",
      "name": "亚马逊标题优化",
      "path": "skills/亚马逊标题优化/",
      "triggers": ["标题怎么写", "优化 listing", ...],
      "keywords": ["亚马逊", "标题", "listing", ...],
      "capabilities": "✅ 能：...\n❌ 不能：...",
      "output_format": "Markdown 清单"
    }
  ]
}
```

## 📖 使用指南

### 调用技能流程

```
用户：「蓝禾技能：标题怎么写」
    ↓
① 获取 manifest.json（1 次 API 调用）
② 在 skills 数组中计算匹配得分
③ 匹配 > 85% → 直接执行
   匹配 60-85% → 显示 Top 2 确认
   匹配 < 60% → 要求细化
④ 获取对应 SKILL.md 并执行
⑤ 询问满意吗？
```

### 上传技能流程

```
1. 对话中描述需求 → AI 生成 SKILL.md → 用户确认
2. 发送「上传蓝禾技能」
3. AI 分析 SKILL.md → 生成 SUMMARY.md 草稿
4. 用户确认摘要（可调整）
5. AI 检查格式 → 不合格则循环修正
6. 更新 SUMMARY.md + manifest.json
7. 推送到 GitHub
```

---

## 📊 匹配规则

| 匹配度 | 处理方式 |
|--------|---------|
| > 85% | 直接执行 |
| 60-85% | 显示 Top 2，用户确认 |
| < 60% | 询问更具体的问题 |

### 评分算法

| 项目 | 最高分 |
|------|--------|
| 触发条件匹配 | 40 |
| 语义关键词重叠 | 60 |
| skill_id 精确匹配 | +20 |

### 纠错机制

- 用户说"不对"、"不是" → 返回下一个最佳匹配
- 连续 3 次失败 → 引导细化问题
