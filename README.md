# 🚀 蓝禾 OpenClaw 工程专属技能库

🎯 打造蓝禾专属的专业技能工具箱！覆盖产品设计、品质保障、元器件选型等工程场景，让评估更标准、更高效！

💪 无论你是工程师、设计师还是产品经理，都可以把自己的专业技能打包成 Skills，方便团队随时调用，一起提升效率！

🔥 让我们一起打造蓝禾专属的 OpenClaw 社区！

---

## 🚀 快速开始

### 调用技能

发送 `蓝禾技能 查询 xxx`，AI 自动匹配并执行相关技能。

### 上传技能

1. 在对话中描述技能需求，AI 生成技能文件
2. 确认内容后，发送 `上传蓝禾技能`
3. AI 完成格式校验与 GitHub 推送

---

## 📁 仓库结构

```
蓝禾技能库/
├── SKILL.md                    # 主入口技能
├── manifest.json               # 技能索引（自动维护）
├── upload-skill/              # 上传技能
│   └── SKILL.md
├── skills/                    # 具体技能
│   └── ...
└── README.md
```

---

## 🔍 工作原理

### 调用流程

```
用户：蓝禾技能 查询 标题怎么写
    ↓
AI 读取 manifest.json（所有技能索引）
    ↓
匹配并执行对应技能
    ↓
返回结果
```

### 上传流程

```
1. 对话中描述需求 → AI 生成 SKILL.md
2. 你确认内容
3. 发送「上传蓝禾技能」
4. AI 生成摘要 → 你确认 → 自动推送 GitHub
```
