# 蓝禾技能库

蓝禾专属 AI 技能库，为 OpenClaw 智能助手提供专业领域能力。

## 架构

```
蓝禾技能库/
├── SKILL.md                    # 主入口技能（路由逻辑）
├── upload-skill/               # 上传技能（创建向导）
│   └── SKILL.md
├── skills/                     # 子技能目录
│   ├── .template/              # 模板文件
│   │   ├── SUMMARY.md
│   │   └── SKILL.md
│   └── 亚马逊标题优化/          # 示例技能
│       ├── SUMMARY.md
│       └── SKILL.md
└── README.md
```

## 使用方式

### 调用技能

发送 `蓝禾技能：xxx` 描述你的问题，AI 会自动：

1. **同步 GitHub** → git pull 拉取最新技能库
2. **匹配技能** → 在 SUMMARY.md 中计算匹配度
3. **执行技能** → 读取 SKILL.md 并执行
4. **确认结果** → 用户满意后结束

### 上传新技能

发送 `上传蓝禾技能`，启动创建向导。

## 技能结构

每个子技能包含两个文件：

| 文件 | 用途 |
|------|------|
| `SUMMARY.md` | 检索摘要，供路由匹配 |
| `SKILL.md` | 完整执行逻辑 |

## 检索机制

### 调用流程

```
用户：「蓝禾技能：标题怎么写」
    ↓
① git pull 同步 GitHub 最新版本
    ↓
② 扫描 skills/ 下所有 SUMMARY.md
    ↓
③ 计算匹配得分
    ↓
④ 返回结果
```

### 匹配规则

| 匹配度 | 处理方式 |
|--------|---------|
| > 85% | 直接执行 |
| 60-85% | 显示 Top 2，用户确认 |
| < 60% | 询问更具体的问题 |

### 评分算法

| 项目 | 最高分 |
|------|--------|
| 触发条件匹配 | 40 |
| 语义关键词重叠 | 60 |
| skill_id 精确匹配 | +20 |

### 纠错机制

- 用户说"不对"、"不是" → 返回下一个最佳匹配
- 连续 3 次失败 → 引导细化问题

## 维护规范

### 新增技能

1. 在对话中描述技能需求
2. AI 生成 SKILL.md → 用户确认
3. 发送 `上传蓝禾技能`
4. AI 生成 SUMMARY.md → 用户确认
5. 自动推送到 GitHub

### 更新技能

1. 修改对应技能的 SKILL.md 或 SUMMARY.md
2. 提交到 GitHub
