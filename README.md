# 蓝禾技能库

蓝禾专属 AI 技能库，为 OpenClaw 智能助手提供专业领域能力。

## 架构

```
蓝禾技能库/
├── SKILL.md                    # 主入口技能（路由逻辑）
├── upload-skill/               # 上传技能（创建向导）
│   └── SKILL.md
├── skills/                     # 子技能目录
│   └── .template/              # 模板文件
│       ├── SUMMARY.md          # 摘要模板
│       └── SKILL.md            # 技能模板
└── README.md
```

## 使用方式

### 调用技能
发送 `蓝禾技能：xxx` 描述你的问题，AI 会自动匹配并执行相关技能。

### 上传新技能
发送 `上传蓝禾技能`，启动技能创建向导。

## 子技能结构

每个子技能包含两个文件：

| 文件 | 用途 |
|------|------|
| `SUMMARY.md` | 检索摘要，供路由匹配 |
| `SKILL.md` | 完整执行逻辑 |

## 检索机制

1. 解析用户问题
2. 在所有 SUMMARY.md 中计算匹配度
3. 综合触发条件（40%）+ 语义关键词（60%）打分
4. 返回最佳匹配并执行

### 匹配规则

| 匹配度 | 处理方式 |
|--------|---------|
| > 85% | 直接执行 |
| 60-85% | 显示 Top 2，用户确认 |
| < 60% | 询问更具体的问题 |

### 纠错机制

- 用户说"不对"、"不是" → 返回下一个最佳匹配
- 连续 3 次失败 → 引导细化问题

## 维护规范

### 新增技能

1. 使用 `上传蓝禾技能` 向导创建
2. 填写 SUMMARY.md 和 SKILL.md
3. 推送到 GitHub 仓库

### 更新技能

1. 修改对应技能的 SUMMARY.md 或 SKILL.md
2. 更新 version 和 updated_at
3. 推送 GitHub
