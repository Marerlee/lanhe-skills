# 蓝禾 OpenClaw 工程专属技能库

本技能库旨在打造符合蓝禾标准与要求的专业技能工具，赋能产品设计开发、品质保障、元器件选型等工程场景，帮助团队实现标准化、专业化的快速评估与决策。

同时，欢迎大家将自己的专业技能封装为可执行的 OpenClaw Skills，方便同事随时调用，提升团队协作效率。

---

## 🚀 快速开始

### 调用技能

发送 `蓝禾技能 查询 xxx`，AI 自动匹配并执行相关技能。

### 上传技能

1. 在对话中描述技能需求，AI 生成技能文件
2. 确认内容后，发送 `上传蓝禾技能`
3. AI 完成格式校验与 GitHub 推送

---

## 📁 仓库结构

```
蓝禾技能库/
├── SKILL.md                    # 主入口技能
├── manifest.json               # 技能索引（自动维护）
├── upload-skill/              # 上传技能
│   └── SKILL.md
├── skills/                    # 具体技能
│   └── ...
└── README.md
```

---

## 🔍 工作原理

### 调用流程

```
用户：蓝禾技能 查询 标题怎么写
    ↓
AI 读取 manifest.json（所有技能索引）
    ↓
匹配并执行对应技能
    ↓
返回结果
```

### 上传流程

```
1. 对话中描述需求 → AI 生成 SKILL.md
2. 你确认内容
3. 发送「上传蓝禾技能」
4. AI 生成摘要 → 你确认 → 自动推送 GitHub
```
