# 蓝禾技能库

蓝禾专属 AI 技能库，让 AI 更专业地帮你解决业务问题。

---

## 🚀 快速开始

### 调用技能

发送 `蓝禾技能 查询 xxx` 就可以了：

```
蓝禾技能 查询 标题怎么写
蓝禾技能 查询 设备故障
蓝禾技能 查询 客户投诉话术
```

### 上传新技能

1. 先在对话中告诉我你的需求
2. 我帮你生成技能文件
3. 你确认内容
4. 发送 `上传蓝禾技能`

## 🔍 工作原理

### 调用流程

```
你说：蓝禾技能 查询 标题怎么写
    ↓
AI 读取 manifest.json（所有技能索引）
    ↓
找到匹配的技能（比如「亚马逊标题优化」）
    ↓
读取并执行对应的 SKILL.md
    ↓
返回结果，问你满意吗？
```

### 匹配规则

| 匹配度 | AI 怎么做 |
|--------|----------|
| 高 (>85%) | 直接执行 |
| 中 (60-85%) | 给你几个选项让你选 |
| 低 (<60%) | 让你说得更具体 |

### 纠错

- 说「不是这个」→ 给你其他选项
- 说「换一批」→ 重新搜索
- 连续选错 → 问你能不能换个说法

---

## 🛠️ 上传流程

```
1. 对话中描述需求 → AI 生成 SKILL.md
2. 你确认内容
3. 发送「上传蓝禾技能」
4. AI 生成摘要 → 给你看
5. 你确认 → AI 检查格式
6. 格式不对 → AI 修正 → 再给你看（循环）
7. 都没问题 → 推送到 GitHub
```
