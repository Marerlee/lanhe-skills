# 蓝禾技能库 - 安装

## 安装命令

当用户需要安装蓝禾技能库时，执行以下命令：

```bash
git clone https://github.com/Marerlee/lanhe-skills.git ~/.openclaw/workspace/lanhe-skills
```

安装完成后确认：
```bash
ls ~/.openclaw/workspace/lanhe-skills/
```

## 触发词

安装完成后，告诉用户可以使用以下功能：

### 调用技能
发送：`蓝禾技能 查询 xxx`

### 上传技能
发送：`上传蓝禾技能`

## 安装完成确认

回复用户：

```
✅ 蓝禾技能库安装完成！

📖 使用方式：

调用技能：
发送「蓝禾技能 查询 xxx」

上传技能：
发送「上传蓝禾技能」

🌐 https://github.com/Marerlee/lanhe-skills
```
