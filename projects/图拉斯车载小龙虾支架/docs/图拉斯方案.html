一、项目概述

1.1 项目背景

小龙虾（OpenClaw）正在成为 AI 时代的现象级产品。

截止2026年3月，小龙虾已经在全球范围内积累了数百万用户，形成了庞大的用户生态。用户通过小龙虾实现了智能家居控制、日常助手、创作辅助等多种场景的 AI 交互。

然而，车场景一直是小龙虾的空白地带。

1.2 市场机会

场景现状痛点
家庭✅ 小龙虾已完美覆盖场景成熟
办公✅ 通过电脑使用体验良好

每天有数亿人次在车内度过时间，无论是通勤路上、外出办公还是长途旅行，车内时光一直是碎片化的空闲时间：

  • 开车时想查询路况
  • 等人时想听新闻
  • 长途旅行想聊天解闷
  • 突发灵感想记录

图拉斯车载小龙虾支架 — 让 AI 助手触手可及

用户只需将手机放在支架上，说一句话，就能与家里的小龙虾实时对话。

4.2 数据流

用户说话 → ESP32录音 → 中继服务器 → STT语音识别 → 文字
    ↓
桥接程序转发 → 小龙虾AI处理 → 回复文字 → 桥接程序
    ↓
TTS语音合成 → 中继服务器 → ESP32播放

4.3 用户绑定流程

  1. 下载桥接程序（图拉斯官网下载页面）
  2. 安装并启动（Windows/macOS/Linux）
  3. 输入设备码（CLAW-XXXXXXXXXXXX）
  4. 桥接程序完成：连接Gateway、验证设备码、建立中继连接
  5. 完成！以后开机自动连接
