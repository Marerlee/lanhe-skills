## 一、项目概述

### 1.1 项目背景

**小龙虾（OpenClaw）正在成为 AI 时代的现象级产品。**

截止2026年3月，小龙虾已经在全球范围内积累了数百万用户，形成了庞大的用户生态。用户通过小龙虾实现了智能家居控制、日常助手、创作辅助等多种场景的 AI 交互。

**然而，车场景一直是小龙虾的空白地带。**

---

### 1.2 市场机会

| 场景 | 现状 | 痛点 |
|------|------|------|
| **家庭** | ✅ 小龙虾已完美覆盖 | 场景成熟 |
| **办公** | ✅ 通过电脑使用 | 体验良好 |
| **车载** | ❌ 完全空白 | 没有合适的交互入口 |

**每天有数亿人次在车内度过时间**，无论是通勤路上、外出办公还是长途旅行，车内时光一直是碎片化的空闲时间。这个场景的用户需求是真实存在的：

- 开车时想查询路况
- 等人时想听新闻
- 长途旅行想聊天解闷
- 突发灵感想记录

**这些都是小龙虾擅长的事情，但用户在车里却没有办法方便地使用。**

## 二、项目意义

### 2.1 对用户的意义

#### 2.1.1 车内 AI 交互的全新体验

**以前：**
- 想问 AI 什么，需要停好车，拿起手机，解锁，打开 App...
- 开车时根本没法操作
- 等人时无聊地刷手机

**现在：**
- 放在支架上，直接说话
- 开车、停车都能用
- 双手不离方向盘，眼睛不离路面

#### 2.1.2 充分利用碎片时间

```
每天平均车内时间：约 60-90 分钟
一年累计：约 365-550 小时

这些时间以前是浪费的，现在可以被 AI 填满：
· 通勤路上听新闻、播客
· 等人时查询信息、聊天
· 长途旅行实时导航、景点咨询
· 突发灵感想记录，回头 AI 帮你整理
```

#### 2.1.3 延续家庭 AI 体验

| 场景 | 以前 | 现在 |
|------|------|------|
| 出门前 | "今天天气怎么样？" | 直接问支架 |

| 回家后 | 继续用家里的小龙虾 | 体验无缝衔接 |

**用户在不同场景下，与同一个 AI 助手的对话记录、记忆、偏好都是连贯的。**

#### 2.1.4 驾驶安全提升

**语音交互比手动操作安全 94%**

| 操作方式 | 视线离开路面时间 | 风险等级 |

| 手动操作手机 | 3-5 秒 | 🔴 高 |

### 4.2 数据流

```
用户说: "明天天气怎么样？"

    │
    ▼

[设备端] 图拉斯支架
├── WakeNet 检测到唤醒词
├── 麦克风阵列录音
├── 音频数据编码
└── 发送到中继服务器

    │
    │ WSS 加密传输
    ▼

[云端] STT 服务器
├── 语音识别
└── "明天天气怎么样"

    │
    ▼

[云端] 中继服务器
└── 路由到用户的桥接程序

    │
    │ 本地 WebSocket
    ▼

[本地] 桥接程序
└── 转发给家里的小龙虾

    │
    ▼

[本地] 小龙虾 Gateway
├── AI 处理
└── 返回文字回复

    │
    ▼

[本地] 桥接程序
└── 提取回复文字，发送到 TTS

    │
    ▼

[云端] TTS 服务器
├── 文字转语音
└── 返回 MP3 音频

    │
    ▼

[云端] 中继服务器
└── 路由到设备

    │
    ▼

[设备端] 图拉斯支架
├── 接收音频
└── 扬声器播放

    │
    ▼

用户听到: "明天多云转晴，最高温度28度..."
```

## 五、组件规格

### 5.1 中继服务器

| 项目 | 规格 |
|------|------|
| **部署方式** | Docker 容器 |
| **服务器配置** | 2核4G 云服务器 |
| **网络带宽** | 5Mbps 共享 |
| **协议** | WebSocket (TLS) |
| **并发设备** | 支持 10,000+ 设备 |

### 5.2 STT 服务器

| 项目 | 规格 |
|------|------|
| **语音识别** | Whisper API / Deepgram |
| **音频格式** | Opus, PCM, WAV |
| **语言** | 中文优先，英文支持 |
| **延迟** | < 500ms |

### 5.3 TTS 服务器

| 项目 | 规格 |
|------|------|
| **语音合成** | Edge-TTS / CosyVoice |
| **音频格式** | MP3, 24kHz |
| **音色** | 中文女声/男声 |
| **延迟** | < 300ms |

### 5.4 桥接程序
