# 线材设计技能

> 根据用户输入的线长和最大电流，计算线材绞合直径。

## 执行所需信息
- 线长 L（单位：m，默认 1m，用户输入 mm 时自动除以 1000 转换）
- 最大电流 I（单位：A，默认 1A）
- 端子数 N（默认：2）
- 端子损耗 G（默认：0.06V）
- 标准压降 V（默认：0.25V）
- 铜电阻率 p（默认：0.0175）
- 铜丝直径 d（默认：0.08mm）

## 执行步骤

### 步骤 1：获取参数
请用户输入以下信息：
- 线长 L（m，用户输入 mm 时自动除以 1000 转换）
- 最大电流 I（A）

其他参数使用默认值：N=2, G=0.06, V=0.25, p=0.0175, d=0.08

### 步骤 2：计算线材电压压降 U
```
U = V - G
```
其中 V 为标准压降，G 为端子损耗

### 步骤 3：计算线材电阻 R
```
R = U / (1.15 × I)
```

### 步骤 4：计算单根电源线截面积 s
```
s = (L × p) / R
```

### 步骤 5：计算铜丝数量 n
```
n = s / (0.7854 × d²)
```

### 步骤 6：计算线材绞合直径 D
```
D = √n × 1.155 × d
```

### 步骤 7：输出结果
向用户展示计算结果，包含：
- 输入参数汇总
- 中间计算值（U、R、s、n）
- 最终结果：线材绞合直径 D（mm）
