# 上传蓝禾技能

> 当用户发送「上传蓝禾技能」时执行此技能。

## 技能信息

- **skill_id**: lanhe-upload-skill
- **version**: 4.0
- **updated_at**: 2026-03-25

## 使用说明

安装此技能后，可以把新技能上传到蓝禾技能库。

### 前提条件

在上传之前，你需要：

```
1. 先在对话中告诉我你要什么技能
2. 我会帮你生成对应的 SKILL.md 文件
3. 你确认内容没问题
4. 然后再发送「上传蓝禾技能」
```

### 简单说就是

```
先聊天生成文件 → 确认文件 → 上传
```

### 如何上传

直接发送：`上传蓝禾技能`

### 上传过程

```
第 1 步：我会问你选哪个技能（从对话里找）
第 2 步：我分析 SKILL.md，生成摘要
第 3 步：把摘要展示给你看
第 4 步：你确认或者让我调整
第 5 步：我检查格式对不对
第 6 步：格式没问题就推送到 GitHub
```

### 举个例子

```
你：我想创建一个"亚马逊标题优化"的技能
我：（生成 SKILL.md）
你：内容可以，这样就行
你：上传蓝禾技能
我：找到"亚马逊标题优化"，确认上传吗？
你：确认
我：（展示摘要...）
你：好的
我：格式检查通过，正在上传...
我：✅ 上传完成！
```

### 格式检查

如果摘要格式不对，我会自动修正再给你看：

```
⚠️ 发现格式有点小问题，我帮你修好了：
• 关键词从 3 个补充到 6 个
• 补全了能力边界

请再确认一下，没问题就上传啦
```

### 完成后

```
✅ 上传成功！

技能：亚马逊标题优化
文件：
• SKILL.md（你的内容）
• SUMMARY.md（摘要）
• manifest.json（已更新）

地址：https://github.com/Marerlee/lanhe-skills
```

---

## 技术说明

### 会更新哪些文件

| 文件 | 说明 |
|------|------|
| `skills/{技能名}/SKILL.md` | 你的技能内容 |
| `skills/{技能名}/SUMMARY.md` | 检索用的摘要 |
| `manifest.json` | 所有技能的索引 |

### manifest.json

这个文件记录了所有技能的信息，上传新技能时会自动把信息加进去，这样调用的时候才能找到。
