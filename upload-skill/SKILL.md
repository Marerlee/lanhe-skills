# 上传蓝禾技能

> 当用户发送「上传蓝禾技能」时执行此技能。

## 技能信息

- **skill_id**: lanhe-upload-skill
- **version**: 3.1
- **updated_at**: 2026-03-25

## 使用说明

安装此技能后，维护人员可以方便地上传新技能到蓝禾技能库。

### 触发方式

发送消息：`上传蓝禾技能`

### 前置条件

在调用此技能之前，需要先在对话中描述并确认技能内容：

```
1. 在对话中描述技能需求
2. AI 生成 SKILL.md
3. 用户确认内容
4. 然后发送「上传蓝禾技能」
```

### 上传流程

```
第 1 步：定位技能
  ↓ 询问用户选择
第 2 步：分析 SKILL.md，提取摘要
  ↓
第 3 步：展示 SUMMARY.md 草稿
  ↓ 用户确认或调整
第 4 步：检查摘要格式
  ↓ 不合格则循环修正
第 5 步：写入 SUMMARY.md
  ↓
第 6 步：更新 manifest.json
  ↓
第 7 步：推送到 GitHub
  ↓
完成！
```

### 用户交互示例

```
AI：🔍 找到你确认的技能：【亚马逊标题优化】
    请确认是否上传？
    1️⃣ 确认上传
    2️⃣ 取消

用户：1

AI：📋 SUMMARY.md 草稿
    【技能名称】亚马逊标题优化
    【skill_id】amazon-title-optimization
    【触发条件】...
    【语义关键词】...
    ...
    
    请确认：
    1️⃣ 确认无误
    2️⃣ 调整

用户：1（确认）
    格式检查：✅ 通过
    ⏳ 正在上传 GitHub...
    
AI：✅ 上传完成！
    🌐 https://github.com/Marerlee/lanhe-skills
```

### 循环检查机制

如果摘要格式检查不通过，会自动修正并重新展示：

```
⚠️ 格式检查未通过
• 语义关键词少于 5 个 → 已自动补充
• 能力边界不完整 → 已自动完善

请再次确认：
1️⃣ 确认无误
2️⃣ 继续调整
```

## 技术细节

### 更新的文件

| 文件 | 说明 |
|------|------|
| `skills/{技能名}/SKILL.md` | 用户的技能内容 |
| `skills/{技能名}/SUMMARY.md` | 生成的检索摘要 |
| `manifest.json` | 更新技能索引 |

### manifest.json 更新内容

```json
{
  "skill_id": "xxx",
  "name": "技能名称",
  "path": "skills/xxx/",
  "triggers": ["问法1", "问法2", ...],
  "keywords": ["关键词1", "关键词2", ...],
  "capabilities": "✅ 能：...\n❌ 不能：...",
  "output_format": "输出格式说明"
}
```

---

## 注意事项

- 上传前请确保 SKILL.md 内容已经用户确认
- manifest.json 是统一索引，**必须同步更新**
- GitHub 推送需要网络连接
- 建议先在测试环境验证，再推送到正式仓库
